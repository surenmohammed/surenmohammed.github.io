Publish to GitHub Pages

Commits site-data.js straight to your repository — the live site updates a minute later. You need a GitHub fine-grained personal access token with Contents: read & write permission for this repository (create one here).

Manual export / backup

Prefer doing it by hand? Download site-data.js and commit it to the repository yourself. JSON export/import is useful as a backup.

How publishing works

All site content lives in one file, site-data.js. Every page reads from it. Publishing simply replaces that file in your GitHub repository, so there is no server or database — and your draft stays private in this browser until you publish.
